# Researcher Guide

Use only de-identified studies. Review every generated mask, contour, measurement line, spectral envelope, calibration artifact, and final report.

For the provided complete high-quality exams, a run that cannot produce required quantitative measurements should be treated as incomplete software extraction work. Repair or replace the relevant parser, calibration extractor, segmentation tool, contour tool, or spectral extractor, then rerun and audit the measurement. Do not use synthetic validation as evidence of clinical performance.
