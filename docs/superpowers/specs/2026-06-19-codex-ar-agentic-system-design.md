# Codex AR Agentic System Design

## Goal

Create a native Codex-orchestrated research scaffold for auditable aortic regurgitation assessment from echocardiography studies, with no external agent orchestration framework and no OpenAI API key.

## Architecture

The parent Codex session is the orchestrator. Project custom agents define specialist roles; repository skills define repeatable workflows; stable Python core modules implement deterministic formulas and threshold interpretation; versioned generated tools support future case-specific adapters.

## Safety

The current complete-exam execution model treats missing calibration, failed extraction, rejected artifacts, and absent quantitative evidence as repairable software/tooling defects. It stores independent JSON outputs, repair requests, and inspectable artifact paths for researcher validation while preserving the no-invented-measurement rule.
